# InnerGReads

The independent digital library and publishing home of Nasirr Mayo and InnerG Intel.

## Current release

- `001`: *Legacy In Ink: The Final Frequency*

The hero uses a self-contained Three.js product viewer built from the final
176-page cover wrap. Readers can drag the physical book, click through the
front/spine/back views, or use the arrow keys.

## Local preview

Open `index.html` directly, or serve this directory with any static web server.

## Adding another release

1. Add the new book assets under `assets/`.
2. Add the book to the shelf in `index.html`.
3. Create a dedicated release section using the structure of release `001`.
4. Keep purchase and preview links specific to that release.
